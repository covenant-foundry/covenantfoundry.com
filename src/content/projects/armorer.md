A beautiful minimal web reader for the King James Version of the Bible.

No ads, commentaries, notes, or distractions. Just the Bible.

Armorer is the Bible reading experience I wanted but couldn't find, so I built it. It's a static site, so it can be hosted cheaply, but uses some Javascript tricks to add infinite scrolling and simple search capabilities.
