# Covenant Foundry

Static Astro prototype for the Covenant Foundry remodel.

## Stack

- Astro 7
- Static output
- CSS and inline SVG for visual patterns
- Real Covenant Foundry logo from the previous main branch

## Commands

```sh
npm run dev
npm run build
npm run preview
```

The current demo page explores a dark industrial Art Deco direction with framed plates, circuit ornament, project cards, build-log panels, and a project-detail surface.
